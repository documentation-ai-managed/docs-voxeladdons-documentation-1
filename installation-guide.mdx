## System Requirements

Before installing VoxelAddons, ensure your environment meets the minimum requirements for optimal performance.

<Columns cols={2}>
  <Card title="Server Requirements" icon="server" href="#server-reqs">
    PHP 7.4+, WordPress 5.0+, Voxel theme 1.0+
  </Card>
  <Card title="Recommended Hosting" icon="cloud" href="#hosting">
    VPS or dedicated server with 2GB+ RAM
  </Card>
</Columns>

<Expandable title="Detailed Requirements" default-open="false">
  | Component | Minimum | Recommended |
  |-----------|---------|-------------|
  | PHP Version | 7.4 | 8.0+ |
  | MySQL | 5.7 | 8.0+ |
  | Memory Limit | 256MB | 512MB+ |
  | Max Execution Time | 30s | 60s+ |

  <Callout kind="alert">Ensure your hosting provider supports the required PHP extensions: curl, json, mbstring, and openssl.</Callout>
</Expandable>

## Installing VoxPro (Foundation)

VoxPro must be installed first as it provides the core framework for all other plugins.

<Steps>
  <Step title="Download Plugin" icon="download">
    Purchase and download VoxPro from the VoxelAddons marketplace.
  </Step>
  <Step title="Upload to WordPress" icon="upload">
    Go to WordPress Admin > Plugins > Add New > Upload Plugin, select the VoxPro zip file.
  </Step>
  <Step title="Activate Plugin" icon="play">
    Click "Activate" to enable VoxPro and initialize the framework.
  </Step>
  <Step title="Run Setup Wizard" icon="settings">
    Access the VoxPro setup wizard from the admin dashboard to configure core settings.
  </Step>
</Steps>

<CodeGroup tabs="WP-CLI,Manual">
  ````bash
  # WP-CLI installation
  wp plugin install voxpro.zip --activate
  ````
  ````bash
  # Manual installation via FTP
  unzip voxpro.zip
  upload to wp-content/plugins/
  activate via WordPress admin
  ````
</CodeGroup>

## Configuration and Setup

After installation, configure each plugin through the unified VoxPro admin dashboard.

<ExpandableGroup>
  <Expandable title="Database Setup">
    VoxPro automatically creates required database tables. For manual setup:
    
    ````sql
    -- Example: Create VoxPro tables (auto-handled)
    CREATE TABLE voxpro_cache (
      cache_key VARCHAR(255) PRIMARY KEY,
      cache_value LONGTEXT,
      expires_at TIMESTAMP
    );
    ````
  </Expandable>
  <Expandable title="Permission Settings">
    Configure user roles and capabilities for plugin access:
    
    <Callout kind="info">Administrators have full access by default. Create custom roles for limited plugin management.</Callout>
  </Expandable>
</ExpandableGroup>

## Troubleshooting Common Issues

<Callout kind="danger">If plugins fail to activate, check PHP error logs and ensure all dependencies are met.</Callout>

<Tabs>
  <Tab title="Activation Errors" icon="alert-triangle">
    Common causes: Missing PHP extensions, insufficient memory, or conflicting plugins.
    
    <Steps>
      <Step title="Check PHP Logs" icon="file-text">Review error logs for specific failure reasons</Step>
      <Step title="Verify Requirements" icon="check">Ensure PHP 7.4+ and required extensions</Step>
      <Step title="Disable Conflicts" icon="x">Temporarily deactivate other plugins to isolate issues</Step>
    </Steps>
  </Tab>
  <Tab title="Database Connection" icon="database">
    Issues with database connectivity or table creation.
    
    ````php
    // Test database connection
    global $wpdb;
    if (!$wpdb->check_connection()) {
      error_log('Database connection failed');
    }
    ````
  </Tab>
</Tabs>
