### Authentication

Secure your API requests using Bearer token authentication.

<Steps>
  <Step title="Generate API Key" icon="key">Create an API key in VoxPro settings with appropriate permissions</Step>
  <Step title="Include in Headers" icon="file-text">Add Authorization header to all API requests</Step>
  <Step title="Handle Token Expiry" icon="clock">Implement token refresh logic for long-running applications</Step>
</Steps>

<CodeGroup tabs="cURL,JavaScript,Python">
  ````bash
  # Example API request with authentication
  curl -X GET /api/voxpro/users \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json"
  ````
  ````javascript
  // JavaScript API client
  const client = new VoxProAPI({ apiKey: 'YOUR_KEY' });
  const users = await client.users.list({ limit: 50 });
  ````
  ````python
  # Python API integration
  import requests
  
  headers = {'Authorization': 'Bearer YOUR_API_KEY'}
  response = requests.get('/api/voxpro/users', headers=headers)
  users = response.json()
  ````
</CodeGroup>

### Rule Engine Integration

Connect external events to the VoxPoints rule engine for automatic point allocation.

<CodeGroup tabs="Webhook,Direct API">
  ````javascript
  // Webhook integration for external events
  app.post('/webhook/order-completed', (req, res) => {
    VoxPoints.API.points.award({
      user_id: req.body.user_id,
      points: 100,
      reason: 'Order completed'
    });
  });
  ````
  ````php
  // Direct API integration
  $pointsAPI = new VoxPoints_API();
  $pointsAPI->award_points($user_id, 100, 'Referral bonus');
  ````
</CodeGroup>

## Error Handling and Rate Limiting

Implement robust error handling and respect API rate limits for reliable integrations.

<Tabs>
  <Tab title="Error Responses" icon="alert-circle">
    Handle API errors gracefully with appropriate retry logic.
    
    | Status Code | Description | Action |
    |-------------|-------------|--------|
    | 400 | Bad Request | Check request parameters |
    | 401 | Unauthorized | Verify API key |
    | 429 | Rate Limited | Implement exponential backoff |
    | 500 | Server Error | Retry with circuit breaker |
  </Tab>
  <Tab title="Rate Limiting" icon="clock">
    VoxPro implements rate limiting to prevent abuse.
    
    <Expandable title="Rate Limit Headers" default-open="false">
      Check response headers for rate limit information.
      
      ```
      X-RateLimit-Limit: 1000
      X-RateLimit-Remaining: 950
      X-RateLimit-Reset: 1640995200
      ```
    </Expandable>
  </Tab>
</Tabs>
