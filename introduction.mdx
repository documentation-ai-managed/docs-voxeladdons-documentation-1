## Welcome to VoxelAddons

VoxelAddons provides a complete suite of plugins that extend the Voxel theme with advanced functionality for marketplaces, directories, and communities. The ecosystem centers around VoxPro as the foundation, with specialized plugins for CRM, payments, gamification, and AI development.

Explore the interconnected plugin architecture that powers modern Voxel installations.

<ExpandableGroup>
  <Expandable title="VoxPro Details">
    The master framework includes 20+ Elementor widgets for authentication, UI components, and toolkit functionality. It provides social authentication with 10 OAuth providers, booking calendars, saved searches, and bulk operations.
    
    <CodeGroup tabs="PHP,JavaScript">
      ````php

      $cache->set('key', 'value', 3600);
      ````
      ````javascript
      // VoxPro JavaScript API
      VoxPro.Bridge.authenticate({
        provider: 'google',
        redirect: '/dashboard'
      });
      ````

## Getting Started

To begin using VoxelAddons, install VoxPro first, then add specialized plugins as needed. The ecosystem is designed for scalability, allowing you to start small and expand functionality over time.
